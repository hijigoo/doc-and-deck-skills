# 주제 조사 요청과 범위

주제는 Microsoft Foundry on Azure이며 청중은 개발자와 기술 의사결정자입니다.
공식 Microsoft Learn 문서를 바탕으로 한국어 기술 입문 자료를 작성합니다.
확인일은 2026-09-30이며 출처 URL과 주장 범위는 sources.json에 보관합니다.

이번 샘플의 추가 조건은 테마별 동봉 템플릿 15종을 모두 한 번씩 사용하는 것입니다.
조사 결과를 foundry.md의 15장 원고로 구성한 뒤 각 topic-to-html 스킬의
자체 deck.html과 조립 도구를 사용합니다. 다른 HTML 스킬 설치는 필요하지 않습니다.

기능 설명과 도입 제안, 실제 상태와 가상 데이터는 구분합니다.
Q&A·네트워크·시퀀스·의사 코드는 설명용 설계이며 실제 배포나 실행 결과가 아닙니다.
지표 템플릿의 40·65·85건은 시각화 예시이며 제품 성과나 벤치마크가 아닙니다.
재생성 스크립트는 이 기록을 재사용하며 새로운 웹 조사를 자동 수행하지 않습니다.
